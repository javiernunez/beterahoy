# Documentación interna — beterahoy.es

Archivo de **contexto editorial** para redactar noticias sobre Bétera (Camp de Túria, Valencia). No es contenido publicable: es memoria de trabajo para periodistas y generadores internos.

## Cómo usar este directorio

- Objetivo: que un redactor entienda un tema en pocos minutos **dentro de dos años**.
- Criterio: **hechos comprobables** primero; declaraciones públicas y análisis mediático, claramente separados.
- Formato estándar de cada ficha: Resumen → Cronología → Hechos → Personas → Entidades → Situación actual → Líneas futuras → Fuentes.
- Enlaces internos con **rutas relativas** desde cada documento.
